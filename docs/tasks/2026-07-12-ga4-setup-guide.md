# Google Analytics 4 初回セットアップ手順（オーナー作業）

**作成日**: 2026-07-12
**対象**: プロジェクトオーナー（GA4 プロパティ未作成）
**関連実装**: `feature/ga4-analytics`（フェーズ4 4.5: アナリティクス導入）

コード側（計測タグの読み込み・プライバシーポリシーへの開示追記）は実装済みです。
環境変数 `NEXT_PUBLIC_GA_MEASUREMENT_ID` が**設定されている場合のみ**計測タグを読み込む実装のため、
以下の GA4 側セットアップと環境変数設定がオーナー作業として必要です（未設定の間は一切計測されません）。

---

## 1. GA4 プロパティとウェブデータストリームの作成

1. https://analytics.google.com に Google アカウントでログインする
2. **管理**（左下の歯車アイコン）→ **作成** → **プロパティ** を選択
   - 初回利用の場合は「測定を開始」から同じ流れになる
3. プロパティの設定:
   - プロパティ名: `FIT-CONNECT`（任意）
   - レポートのタイムゾーン: **日本（GMT+9）Asia/Tokyo**
   - 通貨: **日本円（JPY）**
4. ビジネス情報（業種・規模等）は任意に選択して作成を完了する
5. データ収集の設定で **ウェブ** を選択し、データストリームを作成:
   - ウェブサイトの URL: 本番ドメイン（例: `https://<本番ドメイン>`）
   - ストリーム名: `FIT-CONNECT Web`（任意）

- [ ] GA4 プロパティ（Asia/Tokyo・JPY）を作成した
- [ ] ウェブデータストリームを作成した

---

## 2. 測定 ID の取得

1. **管理** → **データストリーム** → 作成したウェブストリームをクリック
2. 右上に表示される **測定 ID（`G-XXXXXXXXXX` 形式）** を控える

- [ ] 測定 ID（`G-...`）を控えた

---

## 3. 環境変数の設定（Vercel と .env.local）

環境変数は `NEXT_PUBLIC_GA_MEASUREMENT_ID` の1つだけです。

### 3-1. Vercel への設定

1. Vercel ダッシュボード → プロジェクト **fit-connect** → **Settings** → **Environment Variables**
2. `NEXT_PUBLIC_GA_MEASUREMENT_ID` = 手順2で控えた測定 ID（対象環境は Production。
   Preview のアクセスを計測に混ぜたくないため、Preview には設定しないことを推奨）
3. 環境変数はビルド時に読み込まれるため、**設定後に再デプロイ**して反映する

### 3-2. `.env.local` への追記（ローカルで動作確認する場合のみ）

`fit-connect/.env.local` に以下を追記します（値は自分の測定 ID に置き換え）:

```bash
# Google Analytics 4
NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
```

> ⚠️ **値は絶対にこのリポジトリにコミットしないこと。**
> `.env*` は `.gitignore` 済みだが、別ファイル・ドキュメントへの貼り付けも避けること。
> なお、ローカルに設定すると開発中のアクセスも本番の計測に混ざるため、
> 動作確認が済んだら削除（またはコメントアウト）してよい。

- [ ] Vercel に `NEXT_PUBLIC_GA_MEASUREMENT_ID` を登録し、再デプロイした

---

## 4. 動作確認

1. 再デプロイ完了後、本番サイトをブラウザで開く
2. https://analytics.google.com → **レポート** → **リアルタイム** を開く
3. **自分のアクセスが「過去30分間のユーザー」として表示される**ことを確認する
   （反映まで数十秒かかることがある。表示されない場合は、再デプロイ済みか・
   測定 ID が正しいか・広告ブロッカーが有効になっていないかを確認）

- [ ] リアルタイムレポートで自分のアクセスが確認できた
