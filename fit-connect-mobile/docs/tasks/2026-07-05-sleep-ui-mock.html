  • 記録タブに『睡眠』サブタブ新設。並びは サマリ / 体重 / 食事 / 運動 / 睡眠 / ノート（ノートは index 4→5 へ）。

  • ホームの独立カード SleepSummaryCard は廃止し、「今日のまとめ」末尾に睡眠行を追加（indigo100 背景 × indigo600 の moon）。
  • 睡眠行タップで記録タブ『睡眠』へ。未記録の日のみ行内「記録」ミニボタン（primary50/primary・13px/w600・radius 6）→ その場でボトムシート（ホーム完結）。
  • ボトムシート・評価アイコン（すっきり=smile/緑、まあまあ=meh/橙、だるい=frown/赤）は既存の見た目を踏襲（共通ウィジェット化のみ）。
