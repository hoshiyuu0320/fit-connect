# FIT-CONNECT Mobile アプリアイコン

作成日: 2026年10月12日
ブランチ: `feature/mobile-app-icon`

## デザイン

ティールの背景に、白い F と C を組み合わせた FC モノグラムを配置し、C の上部にミントのアクセントを加えた。太い形と余白で、ホーム画面の小さい表示でも FIT-CONNECT の頭文字を判別しやすくした。外周の角丸は画像に焼き込まず、OS側の表示に委ねる。

## 生成方法と保存先

- ツール: 組み込み `image_gen.imagegen`（imagegen スキルの built-in tool mode）
- FC モノグラムは新規生成1回。CLI / API fallback は使用していない。
- 生成時の設定: `transparent_background: false`
- 生成原本: 1254×1254 PNG、アルファチャンネルなし
- 最終マスター: `assets/branding/fit-connect-app-icon.png`（macOS `sips` で1024×1024へ縮小したPNG、アルファチャンネルなし）
- 生成スクリプト: `tool/generate_app_icons.py`
- iOS: `ios/Runner/Assets.xcassets/AppIcon.appiconset/` の15 PNG（20〜1024px）
- Android: `android/app/src/main/res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png` の5 PNG（48/72/96/144/192px）

## 再生成

macOS の `sips` と Python 3 を使用する。Mobileディレクトリから実行する。

```sh
python3 tool/generate_app_icons.py
```

スクリプトは既存の iOS `Contents.json` に記載されたサイズ・ファイル名と Android の5密度から出力を決め、PNGのサイズとアルファチャンネルがないことを検証する。リポジトリ内のマスターから各サイズを生成できる。下記のAI画像生成プロンプトは制作記録であり、同一ピクセルの再生成を保証しない。

## Android 通知アイコン

ランチャーの不透明PNGを通知の小アイコンに流用すると、Android の単色表示で四角になるため、`android/app/src/main/res/drawable/ic_stat_fit_connect.xml` を追加した。24dp / 24×24 viewport の透明背景に白い FC シルエットを描くネイティブ VectorDrawable とし、追加依存は使用していない。

`AndroidInitializationSettings('ic_stat_fit_connect')` と FCM の `com.google.firebase.messaging.default_notification_icon` をこの drawable に統一。フォアグラウンド通知・同期エラー通知には個別のアイコン指定がないため、初期化時の既定値が使われる。ランチャーは引き続き `@mipmap/ic_launcher` を使用する。
